# 코레일 KTX 자동 예매 (터미널)

매진된 KTX 열차를 계속 조회하다가 좌석이 나오면 바로 예약하거나 알려주는 터미널 프로그램입니다.
예약 조건은 터미널에서 입력하고, 진행 상황과 결과도 터미널에 표시됩니다.
좌석이 나오면 macOS 알림과 소리로 알려주고, 설정하면 [ntfy](https://ntfy.sh)로 휴대폰에도 알림을 보냅니다.

## 빠른 시작

```bash
make install     # .venv 생성 + 패키지 설치 (처음 한 번만)
cp .env.example .env   # 선택: 코레일 아이디/비밀번호 저장
make run         # 실행
```

`make`를 쓰지 않는다면:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python src/cli.py
```

## 사용법

실행하면 먼저 모드를 고릅니다.

| 모드 | 동작 | 로그인 |
|---|---|---|
| `1` 자동 예약 | 자리가 나면 바로 예약하고, 결제는 직접 합니다 | 필요 |
| `2` 알림만 | 원하는 좌석 등급에 자리가 나면 알리고 종료합니다. 예약은 직접 합니다 | 필요 없음 |

그다음 조건을 차례대로 물어봅니다.

| 항목 | 입력 예시 | 참고 |
|---|---|---|
| 출발일 | `20261030` | 8자리 |
| 출발역 / 도착역 | `서울`, `부산` | "역"은 빼고 입력 |
| 검색 시작 시각 | `0800` | HHMM |
| 검색 최대 시각 | `1200` | `2400` = 제한 없음 |
| 열차 종류 | `1` | 1: KTX만, 2: 모든 열차 |
| 좌석 | `1` | 1: 일반실 우선, 2: 일반실만, 3: 특실 우선, 4: 특실만 |
| 탑승 인원 | `1` | 1~9명, 자동 예약 모드에서 2명 이상이면 연속/랜덤 배치 선택 |

마지막에 `Y`를 입력하면 조회가 시작됩니다. 약 1분마다 진행 상황이 표시되고, `Ctrl + C`로 언제든 중단할 수 있습니다.

좌석이 잡히면 **10분 안에** 코레일톡 앱이나 [letskorail.com](https://www.letskorail.com)에서 결제해야 합니다. 결제하지 않으면 예약이 자동 취소됩니다.

조회하는 동안에는 Mac이 잠자기에 들어가지 않게 해주세요. 예: 다른 터미널에서 `caffeinate -i` 실행.

## 환경변수 (`.env`)

| 변수명 | 기본값 | 설명 |
|---|---|---|
| `USERID` | - | 코레일 아이디 (회원번호, 휴대폰 번호 `010-xxxx-xxxx`, 이메일). 비워두면 실행할 때 물어봅니다 |
| `USERPW` | - | 코레일 비밀번호. 비워두면 실행할 때 물어봅니다 (화면에 표시되지 않음) |
| `SEARCH_INTERVAL` | `1` | 조회 간격(초). **1보다 줄이지 마세요** |
| `PAYMENT_TIMEOUT_MINUTES` | `10` | 예약 성공 후 안내하는 결제 기한(분) |
| `NTFY_TOPIC` | - | 휴대폰 알림을 받을 ntfy 토픽. 비워두면 Mac 알림만 보냅니다 |
| `NTFY_SERVER` | `https://ntfy.sh` | ntfy를 직접 운영할 때만 바꾸세요 |
| `LOG_LEVEL` | `INFO` | `DEBUG`로 바꾸면 조회 과정이 자세히 표시됩니다 |

## 휴대폰 알림 (ntfy)

1. 휴대폰에 ntfy 앱(iOS/Android)을 설치합니다.
2. 남이 추측하기 어려운 토픽 이름을 정합니다. 예: `korail-$(openssl rand -hex 8)`
   공용 서버라 토픽 이름을 아는 사람은 누구나 알림을 볼 수 있습니다.
3. 앱에서 그 토픽을 구독하고, `.env`에 `NTFY_TOPIC=토픽이름`을 적습니다.

알림을 누르면 결제 페이지(자동 예약) 또는 레츠코레일(알림만)이 열립니다.

## 주의사항

1. 개인 용도로만 사용하세요. 상업적 이용을 금합니다.
2. 조회 간격을 1초보다 짧게 설정하지 마세요. 코레일 서버에 부담을 주고, 계정이 정지될 수 있습니다.
3. 코레일은 매크로 사용을 제한하고 있습니다. 코레일 측 변경으로 로그인이 거부될 수 있으며
   (예: "매크로 등 미허가 도구 사용 시 이용이 제한될 수 있습니다"). 이 응답을 받으면 프로그램은 재시도하지 않고 바로 종료하며,
   korail2 라이브러리가 업데이트될 때까지 사용할 수 없습니다. 2026-10-28 기준으로 조회 요청이 이 응답으로 막히고 있습니다.
   급할 때는 코레일톡 앱의 공식 **예약대기** 기능을 이용하세요.

## 개발

```bash
make install   # 테스트 도구(pytest) 포함 설치
make test      # 테스트 실행
```

## 프로젝트 구조

```
src/
├── cli.py                  # 터미널 진입점 (입력, 진행 표시, 알림)
├── config/settings.py      # 환경변수 설정
├── services/korail_service.py  # 조회·예약 루프 (korail2 래퍼)
└── utils/                  # 입력 검증, 역 목록, 알림, 로깅
tests/unit/                 # 입력 검증, 조회 루프, 알림 테스트
```
